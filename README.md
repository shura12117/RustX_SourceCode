Слив моделей, сцен, текстур, карт, спрайтов и прочих ресурсов из игры **RustX**. Представляет собой полностью выгруженную базу ассетов, готовую к изучению, переиспользованию и сборке собственного проекта.

## 📦 Что внутри

### 🎨 Ассеты
| Категория        | Кол-во  | Формат  |
|------------------|---------|---------|
| Текстуры         | 792     | PNG     |
| Спрайты          | 435     | PNG     |
| Шейдеры          | 104     | shader  |
| Материалы        | 117     | mat/yaml|
| Меши (3D)        | 24      | OBJ/bin |
| Префабы (GameObject) | 11 751 | YAML |
| Анимации         | 35      | anim    |

| Шрифты           | 8       | font    |

### 🗺️ Карты
Три карты Unturned в исходном виде:

- `Maps/Combat`
- `Maps/Flexborn`
- `Maps/Waterside`

> Полные структуры карт: ландшафт, сплавмапы, хайтмапы, объекты, спавны, деревья, дороги.

### 📦 Контент-паки
- `Bundles/xMod` — предметы: оружие, одежда, постройки, скины
- `Bundles/xPack` — окружение: локации, ресурсы, валуны, техника

### 📁 Прочее
- `Data_управление_сценами` — сцены `level0–3`, `globalgamemanagers`, `sharedassets`
- `Localization` — локализация EN/RU
- `DLL_исходные` — `Ham.dll` / `Nam.dll` / `Pam.dll`
- `Extras` — шаблоны уровней

## ⚠️ Структура папок

```
RustX_Исходники/
├── Ассеты/                  # Извлечённые ресурсы
│   ├── Texture2D/           # Текстуры
│   ├── Sprite/              # Спрайты
│   ├── Mesh/                # 3D-меши
│   ├── shader/              # Шейдеры
│   └── ...
├── Bundles/                 # Контент-паки xMod / xPack
├── Maps/                    # Карты Combat / Flexborn / Waterside
├── Data_управление_сценами/ # Сцены и globalgamemanagers
├── DLL_исходные/            # Сборки
└── Localization/            # EN / RU
```
